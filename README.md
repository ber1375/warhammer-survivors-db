# Warhammer Survivors DB

Warhammer Survivors DB is an unofficial game reference and build planner for **Warhammer Survivors**, covering both **Warhammer 40,000** and **Warhammer Age of Sigmar**.

[Open Warhammer Survivors DB](https://ber1375.github.io/warhammer-survivors-db/)

## Features

- **Codex** — Browse characters, weapons, passive items, and stages. Look up stats, unlock requirements, weapon evolutions, and rewards.
- **Build planner** — Choose a character and stage, pick weapons and passive items, check evolution requirements, and see which items you can pick up on the selected stage.

Your builds and language preference are saved in your browser.

## Data sources

The project uses data from the Windows Steam version of Warhammer Survivors. The interface displays the Steam build number. After a game update, findings that need to be checked again are flagged in the **Needs Review** section.
